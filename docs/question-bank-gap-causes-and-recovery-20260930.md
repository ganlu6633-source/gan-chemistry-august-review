# 四个年级题库缺口：已查明的原因与逐题修复记录（2026-09-30）

这份记录把“电脑里有多少材料”“自动程序看似找到多少题”“学生今天能直接做多少题”分开计数。材料总数不能冒充题数；只有题干、完整四项、答案、解析、原页和知识点都核过，才进入学生端。

| 位置与时间 | 核到的数量 | 这些数量说明什么 |
| --- | ---: | --- |
| 本地材料登记（旧快照） | 24,316 条材料记录 | 包含 Word、PDF、图片、视频等；不是 24,316 道题。 |
| 自动提取（旧快照） | 1,196,378 个候选片段 | 同题可被多次切片，也包含填空、解答、图注或缺字；不能当独立题。 |
| 自动候选中带四项 / 答案 / 解析 | 120,591 / 5,333 / 6,979 | 三项同时存在仅 1,877 个候选，仍可能重复、错图或公式丢失。 |
| 旧版线上记录 / 当时来源仍启用 / 当时可练 | 5,922 / 1,654 / 669 | 旧版、待发布版和核过的成品混在记录总量里，669 才是当时可练数。 |
| 本轮修复后 2026-09-30 的一次在线快照 | 初三 366、高一 454、高二 221、高三 480 | 合计 1,521 道可练；并行修复仍在进行，后续会变。 |

差距不是单一导入开关造成的，已追到以下具体环节：

1. **本地资料没全进入主索引。** 两个 U 盘重新按文件内容核对后，有 927 份独立文件未在主登记或可复用旧索引找到；其中包括 543 份 Word 和 51 份 PDF。这些材料要先配学生版与教师版，不能只按文件名猜同题。
2. **自动文字稿会丢化学结构。** 抽查 1,611 对学生/教师 Word 后，1,493 对存在上下标、公式对象、图片或字段等结构风险；文字看似相符，也不能证明电荷、反应箭头和题图完整。高三离子式、图像题已经实测发生过这种错。
3. **部分来源本身就有缺项或争议。** 有的原生 Word 中选项公式就是空的；有的教师版答案或解析与守恒、计算不一致。这样的题不能凭一个答案字母“补”出题干，更不能直接发学生。
4. **旧线上记录混有历史版和重复题。** 5,922 是记录行数，不是互不重复的成品题。近期初三 6.1 的 7 道题经原页对照发现已在另一条学习路线可练，重复检查因此拦住二次入库。
5. **原来的提示语把局部检查说成了全站。** “0 道仍可下发”仅指上一轮检出的 39 道公式破损旧版，不表示整站没有可练题；此口径应在教师界面改清楚。

目前的处理顺序是按原件去重、找学生/教师对应页、重做紧凑原题图和教师解析图、逐项核答案与化学判断、放入细分知识点、模拟发布失败时回滚，最后检查学生自选目录和图片校验。学生端对尚有公式占位、缺原图、缺逐项解析或原答案有争议的版本继续拦截。这样会慢于单纯批量搬文字，但修复的是学生实际会遇到的错题和空题，而非只把数字做大。

本轮可追查的补题记录包括高二专题 3 的 [第一批 8 道](high2-topic3-original-source-eight-20260930.md)、[第二批 8 道](high2-topic3-second-eight-originals-20260930.md)和[其余 8 道](high2-topic3-last-mcq-originals-20260930.md)，以及各年级原题修复记录。上述 1,521 道仍远未覆盖所有本地材料；未核完的不能写成“已全部上线”。
