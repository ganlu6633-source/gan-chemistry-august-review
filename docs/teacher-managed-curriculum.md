# 教师课程管理与材料入库说明

2026-09-12。本次扩展保留学生现有的四选一作答方式：读原题、在纸上思考或打草稿、选择 A–D、提交后看系统判分与解析。

## 教师后台操作

“学生管理”可以添加、编辑、移出和恢复学生。新学生可选择年段、所属班级及参照学生的教学起点。只继承教材和课程起点，个人成绩、错题、掌握证据从零积累。移出学生会停用登录及现有会话，历史记录保留；恢复后原登录码可继续使用。

“课程管理”可按学生或同进度组排课，搜索知识点并勾选要安排的内容，设定日期和题数。已有安排默认保留；已开始的安排不能被清除。预览会列出新增、保留和移除的安排，再保存。若预览后学生开始作答或题库发生变化，保存会要求重新预览。

课程目录中的数量表示不同范围：可练题必须通过完整来源与图片审核；待核材料只供教师检索，不能直接给学生发题。大块知识点可展开查看细项，也可搜索定位。新材料作为可选课程内容加入，不自动替换学生正在做的原题。

## 实现约束

教师管理接口使用原有服务器会话校验，管理表及私有原题图片不允许浏览器直接读取。补充教材使用独立的已核发布，与原有题库并存。新课程必须指向服务器保存的固定题组；跨年段内容只由教师安排的来源年段授权，不能通过客户端年段参数自行解锁。

原题图必须属于服务器当轮实际下发的题目，解析图需要本人提交后的答案锁或已完成历史证据。原题版本改变时旧答案不能覆盖新版本，历史快照保留。教师预览不写入学生成绩。

本地数据与私有题图不加入公开静态资源。公开仓库只发布页面、业务代码及迁移说明。完整候选明细、逐题源定位、核验过程与导入记录保存在本地工作目录。
