# 甘老师化学学习系统 V2

一个统一数据层支撑的三角色化学学习系统：

正式入口使用“姓名 + 登录码”，系统按登录码自动进入学生、家长或甘老师对应的页面。家长姓名在家长码验证成功后采集，因此爸爸、妈妈或其他监护人可分别留下自己的姓名并关联到同一学生。

全部现行高中复习日历统一设置为连续 40 天：2026-08-17（周一）为第 1 天，至 2026-09-25。日历按自然周展示；高三计划以 2026-08-27 福州质检倒排，质检后转入订正和迁移回收。

高一计划采用严格的“学到哪里测到哪里”边界：基础进度组只测已讲的周期律、物质分类、物质的量/阿伏加德罗常数/摩尔质量和气体摩尔体积；已学氧化还原组在这些内容上每天加入氧化还原。新高二覆盖选择性必修一。完整验收口径见 `docs/PROGRESS_ALIGNMENT_QA_20260812.md`。

- 学生端：REVIEW 长期复习、40 天可点击计划、每日 3—5 个知识点摘要、知识卡、自适应练习、能力星图和成长记录。未来日期只进入独立的只读知识预习页，不展示正式题目、答案或提示，也不形成掌握度证据；到计划日期后再进入正式题组。独立课堂小测站不属于本仓库的本轮发布范围。
- 家长端：30 秒读懂进步、关注点、遗忘回收、行为证据与教师行动，不展示内部标签。
- 教师端：使用与首页一致的“姓名 + 8位登录码”进入私密工作台，可查看学生档案、课堂记录、课程地图审核、题库审核和访问码重置。

## 本地运行

```bash
pnpm install
pnpm dev
```

创建 `.env.local` 并参考 `.env.example`。浏览器端只能使用 Supabase publishable key，任何 service role key 都不得进入前端或仓库。

## 质量检查

```bash
pnpm validate:content
pnpm validate:edge
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
```

`pnpm validate:edge` 会同时构建两个 Edge Function 入口，并用固定版本 Deno 对入口和本地依赖做完整静态检查；前端 `tsc` 只覆盖 `src`，不能替代这一步。

`pnpm publish:static` 会先生产构建，再把经过构建的静态文件复制到仓库根目录，供当前 GitHub Pages 的 main/root 发布方式使用。源码入口保存在 `app.html`；根目录 `index.html` 是自动生成的生产文件。

GitHub Pages 只发布静态文件，不会自动执行 Supabase migrations 或部署 Edge Functions；数据库和函数必须分别部署，并在目标环境完成预检、登录和业务烟测。

## 数据与隐私

- 真实学生档案和访问码明文不进入公开仓库。
- 学生码和家长码完全独立；数据库只保存 bcrypt 强哈希和两位非敏感检索前缀。
- 所有公开 schema 表均启用 RLS，并显式拒绝浏览器直接访问；业务读写只经过职责分离的 Edge Functions。
- 教师内部备注不会进入学生或家长 DTO。
- 商业教辅正文没有复制进公开仓库。初三本地材料只在被忽略的私有导入区处理；仓库仅保存不含题面、选项、答案、解析、提示和路径的审计元数据。该内容按“用户提供、本系统私下使用、未核验再传播授权”处理，不作出版授权声明。
