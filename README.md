# 甘老师化学学习系统 V2

一个统一数据层支撑的三角色化学学习系统：

正式入口使用“姓名 + 登录码”，系统按登录码自动进入学生端或家长端。家长姓名在家长码验证成功后采集，因此爸爸、妈妈或其他监护人可分别留下自己的姓名并关联到同一学生。

正式复习日历按学生进度设置连续 40 天：洪杰、天佑、肖欣慧、浩洋、浩霖从 2026-08-15（周六）开始，第 1 天为 8 月 15 日，至 9 月 23 日；其他现行学生仍按原定 8 月 1 日至 9 月 9 日执行。每人的首个短周之后按自然周展示。高三计划以 2026-08-27 福州质检倒排，质检后转入订正和迁移回收。

高一计划采用严格的“学到哪里测到哪里”边界：正在上课组只测已讲的周期律、分类第一讲、电解质概念及物质的量/阿伏加德罗常数/摩尔质量；已完成课组增加氧化还原。新高二覆盖选择性必修一。完整验收口径见 `docs/PROGRESS_ALIGNMENT_QA_20260812.md`。

- 学生端：REVIEW 长期复习、40 天可点击计划、每日 3—5 个知识点摘要、知识卡、自适应练习、能力星图和成长记录。独立课堂小测站不属于本仓库的本轮发布范围。
- 家长端：30 秒读懂进步、关注点、遗忘回收、行为证据与教师行动，不展示内部标签。
- 教师端：Supabase Auth 魔法链接、学生档案、课堂记录、课程地图审核、题库审核和访问码重置。

## 本地运行

```bash
pnpm install
pnpm dev
```

创建 `.env.local` 并参考 `.env.example`。浏览器端只能使用 Supabase publishable key，任何 service role key 都不得进入前端或仓库。

## 质量检查

```bash
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
```

`pnpm publish:static` 会先生产构建，再把经过构建的静态文件复制到仓库根目录，供当前 GitHub Pages 的 main/root 发布方式使用。源码入口保存在 `app.html`；根目录 `index.html` 是自动生成的生产文件。

## 数据与隐私

- 真实学生档案和访问码明文不进入公开仓库。
- 学生码和家长码完全独立；数据库只保存 bcrypt 强哈希和两位非敏感检索前缀。
- 所有公开 schema 表均启用 RLS，并显式拒绝浏览器直接访问；业务读写只经过职责分离的 Edge Functions。
- 教师内部备注不会进入学生或家长 DTO。
- 商业教辅材料没有复制进本仓库；首发题目为原创或原创变式，并带福建范围状态。
